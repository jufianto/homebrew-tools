# jufianto/tools

Homebrew tap for my tools.

```sh
brew tap jufianto/tools
brew install jufianto/tools/batlog
```

| Tool | What it is |
|---|---|
| [batlog](https://github.com/jufianto/batlog) | Record your Mac's battery and per-app energy in the background, and find out what drained it |

Casks in `Casks/` are generated by [GoReleaser](https://goreleaser.com) on
each release. Don't edit them by hand; fix `.goreleaser.yaml` in the tool's
repository instead.
